`main.py` (Python 3.13, standard library only) writes a single line to `/output/entry.txt`. The joke sets up a modern, concrete scene — a screen-time report, the weekly scolding every phone owner knows — then turns on the last clause: the addiction is so reliable it earned loyalty-program status. Deadpan, retellable, no explanation after the punchline. The output is deterministic: every run writes the same line, 94 characters as the gate requires (1 line, 1–200 characters).
